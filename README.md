# 掼蛋（单机自娱自乐版）

一个能在浏览器里直接打开的单机掼蛋工具，自己一个人就能打，用来练理牌、出牌、记牌和复盘。不联网、不注册、不下载任何东西，打开一个网页文件就能玩。

这是「生晟AI工坊」里的第一件开源工具。

## 这是什么

- 单机四家掼蛋，你打一家，另外三家由程序接手。
- 会提示你出什么比较好，每一手都讲得出依据，方便复盘。
- 能记牌、看牌谱、导出复盘日志。
- 全部逻辑写死在网页里，纯本地运行，没有服务器，不收集任何信息。

## 怎么装、怎么用

1. 下载本仓库的 `掼蛋.html`（整个工具就这一个文件）。
2. 双击用浏览器打开，推荐 Chrome 或 Edge，别的现代浏览器一般也行。
3. 打开就能打，不用装软件、不用注册账号。

想让工具记住难度和窗口位置，浏览器本地存储就够了。想导出复盘日志，点顶栏的「日志」按钮，选一个本地目录保存即可。

## 关于引擎

出牌逻辑是一套写死的规则，不训练、不联网、不调用任何模型。策略规则参考了公开的掼蛋实战资料，出牌强弱用公开牌局数据集做过校准，数据集来自金山 AI 与南京邮电大学公开的掼蛋牌局数据。代码是自己在这些依据上手写的，没有把数据集原文打包进仓库。
